# ALU AirBnB Clone

This project is a clone of the AirBnB web application, developed as part of the ALX Software Engineering program. It is the first step towards building a full web application — starting with a command-line interface (CLI) that simulates the backend and data storage operations.

## Description

The goal of this project is to build a simplified version of the AirBnB platform using Python. It includes a custom command interpreter to manipulate data stored in a JSON file, emulating a database. The application manages different objects such as users, places, reviews, etc., through object-oriented programming.

## Command Interpreter

The command interpreter provides an interactive shell environment to manage the AirBnB data models. It allows users to create, update, delete, and display object instances from the command line.
